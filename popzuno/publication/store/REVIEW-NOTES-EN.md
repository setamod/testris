# Popzuno — reviewer notes

Candidate 0.9.8, build 17. Bundle/application ID: com.mertbekisoglu.bulusko. Paid download; no ads or in-app purchases. No login or demo account is required.

- The complete game is bundled and works offline. Tap Start, then swipe neighboring faces or tap two neighbors to form a line of three or a 2×2 square. The ? menu explains all reward patterns and controls.
- Five modes: Rush, Blitz 60, Time Rush, Ascend and Daily 90. Daily uses a UTC-day seed and local records; it is not a network leaderboard.
- Optional My family photos are processed locally. Default illustrated characters provide full gameplay without photo access. The app locates/crops faces; it does not identify people or upload photos.
- Music starts after user interaction. Pausing/backgrounding stops gameplay and audio. Haptic feedback requires supported physical hardware and enabled settings.
- Six languages are available in the ? menu. Android ships all six language resources together for offline switching.
- ? → Privacy and licenses contains the policy and third-party notices. Delete all game data requires a confirmation and removes local names, photos, records and preferences. Original gallery files and existing OS backups are not changed.
- iOS has native haptics/settings and an optional system photo/camera picker; Android uses the system image/document picker and haptics, without broad gallery or internet permission.
- Sharing is user initiated and sends only a result text. Support opens the user's email app; it does not automatically send a message or logs.

- The main menu previews mode goals and end rules; returning there pauses an existing run. Countdown/overflow cues respect Reduced Motion. Full-screen results state the exact ending cause.
- Seven expressive synthetic announcer clips were generated during asset production using MIT-licensed Chatterbox and a synthetic-only Apache-licensed Kokoro reference; only 416 KB of outputs ship, retaining the default PerTh watermark. The app does not ship a speech-generation model or call a network voice service. Installed offline system voices are retained only as a decoder-unavailable fallback. Existing local face detection is separate. No human reference recording was used for the clips. See bundled music/voice notice and vendor provenance.

Familytris is a fully playable, offline block-puzzle game with a Turkish interface.
No account, login, server access, advertising, in-app purchases, or external content download is needed.

To play:
1. Tap "Oyuna başla" (Start).
2. Use the lower controls: left / rotate / right; hold / down / hard drop.
3. Complete horizontal rows. The game speeds up every ten rows.
4. Tap the speaker icon to toggle sound. Sounds respect the iPhone silent switch.
5. Tap the ? button, then "Uygulama ayarları ve gizlilik" for the native haptic setting, privacy information and font licenses.

The game is rendered by WebKit from a bundled local HTML file. It does not load a hosted website or download executable game content. The app includes native haptic feedback, native settings, app-specific persistent high-score/preferences storage, and lifecycle/interruption handling.

All game assets and fonts are bundled. No personal data is collected or transmitted. High score, sound preferences and the haptic preference are stored only on the device.

Before submission, add the actual review contact in App Store Connect and verify the submitted build on a physical iPhone.

Personalization: tap Ailem, select up to seven face photos, and wait for local processing. No server receives images. Photos may be removed with Sil; playing without photos is also supported. Face detection uses bundled pico (MIT).
